htmx Gantt chart over a server task table

The server renders a plain task table inside a data-lattice-gantt element. Lattice turns it into a task grid and a timeline, re-raises every drag as a lattice:gantt-change event for hx-post, and puts the zoom back when you press Back. There is no mount code on this page: only markup, htmx and the Lattice htmx module.

A stand-in server is answering in your browser. GitHub Pages is static, so a small script answers htmx's requests to /htmx-demo/ with HTML built from demo data in memory, after a short delay so each swap is visible. Nothing leaves the page. Its route handlers are printed below: they are what your own server would do.

Try the five steps

  1. Built on load. The task table was server-rendered; the Gantt replaced it with a task grid and a timeline.
  2. Swap. Pick the other project. hx-get fetches its tasks, the old Gantt is torn down and a new one is built.
  3. Out of band. Press "Server slips one task". One task comes back out of band and its bar moves a day.
  4. Edit. Drag a bar to new dates, or edit a cell. lattice:gantt-change is posted with hx-post and the server confirms below the chart.
  5. Back. Click Month in the timeline header, switch project, then press Back. The zoom returns to Month.
