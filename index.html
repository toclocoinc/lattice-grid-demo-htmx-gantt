htmx Gantt chart over a server task table

The server renders a plain task table for a two-year programme, with phases, milestones and linked tasks; Lattice turns it into a Gantt chart with no mount code, and htmx handles the swaps, the out-of-band update and the save. A stand-in server answers htmx's requests in your browser, so nothing leaves the page.

    Try the five steps

    1. Built on load. The task table was server-rendered; the Gantt replaced it with a task grid and a timeline.
    2. Swap. Pick the other project. hx-get fetches its tasks, the old Gantt is torn down and a new one is built.
    3. Out of band. Press "Server slips one task". One unfinished task comes back out of band and its bar moves a week.
    4. Edit. Drag a task bar to new dates. The whole edit, including the linked tasks it reschedules, arrives as one lattice:gantt-commit event, posted with a single hx-post; the server confirms below the chart.
    5. Back. Click Quarter in the timeline header, switch project, then press Back. The zoom returns to Quarter.
